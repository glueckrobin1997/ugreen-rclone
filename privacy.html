Privacy Policy

This application is used exclusively for personal file synchronization between a private UGREEN NAS and Google Drive using rclone.

Google Drive Data

The application accesses Google Drive data solely for the purpose of synchronizing files requested by the user.

Google Drive data is not sold, shared with third parties, or used for advertising purposes.

Authentication

Google OAuth authentication is used to authorize access to the user's Google Drive account. Authentication credentials and tokens are used by rclone on the user's private system.

Data Storage

This website does not collect or store Google user data. File synchronization is performed directly between the user's systems and Google Drive.

Purpose

This OAuth application is a private, non-commercial application and is not made available as a service to other users.
